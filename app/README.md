# تطبيق «مسائل الشاطبية» (PHP)

تطبيق لتصفح المسائل ومراجعتها، مبني فوق قاعدة المحتوى `data/out/qiraat.db`.

## ما فيه
- **القراءات:** تصفية بالقارئ أو الراوي، والسورة ومدى الآيات، والنوع (فرش/أصول)، والباب، والحال (وصل/وقف)، والبحث بلا تشكيل، و«ما خالف حفصًا فقط»، و«ما عليه مراجعة».
  - الرواة المتفقون في الموضع يُجمعون في صف واحد.
  - لكل قراءة دليلها من النظم ورمزها.
  - التنزيل بصيغة CSV.
- **الجدول:** صف لكل موضع، وعمود لكل راوٍ مختار.
- **المسائل:** صفحة لكل مسألة فيها الأبيات، وقول الشاطبي، والقراءات بأصحابها، والمواضع، والمراجعات.
- **المتن:** الأبيات حسب الأبواب، وبحث في المتن، وروابط إلى المسائل التي يستشهد بها كل بيت.
- **المراجعة:**
  - يبلّغ المراجع عن خطأ بعلامة ⚑ في أي من: مسألة، أو قراءة، أو موضع، أو قراءة راوٍ في موضع، أو بيت من المتن، أو ملاحظة عامة.
  - تُحفظ مع البلاغ القيمة الحالية ونسخة المحتوى.
  - يتناقش المراجعون، ويقبل المشرف البلاغ أو يرفضه، ثم يصدّر المقبول.

## التشغيل محليًّا
يتطلب PHP 8.1 فأعلى مع `pdo_sqlite` و`mbstring`.

```
python scripts/build_masail.py                       # يولّد data/out/qiraat.db
cp app/config.example.php app/config.php             # ثم عدّل القيم إن لزم
php app/bin/create_user.php admin "اسم المشرف" admin  # يسأل عن كلمة المرور
php -S 127.0.0.1:8090 -t app/public
```

## النشر على استضافة
1. ارفع المجلد `app/` والملف `data/out/qiraat.db`، مع الحفاظ على المسار النسبي، أو عدّل `content_db` في `config.php`.
2. اجعل جذر الموقع (document root) هو `app/public`، حتى لا تكون `src` و`data` و`config.php` متاحة من الويب.
3. يجب أن يكون `app/data/` قابلًا للكتابة. فيه `reviews.db` (المستخدمون والمراجعات)، ويُنشأ تلقائيًّا.
4. أنشئ حساب المشرف الأول بـ `bin/create_user.php`، وما بعده من حسابات من صفحة «المستخدمون».
5. اضبط `public_read` على `false` إن أردت أن يكون التصفح كله بعد الدخول.

## دورة التصحيح
مصدر الحقيقة هو ملفات `data/masail/*.yaml` في git. التطبيق لا يغيّر المحتوى مباشرة، بل يجمع البلاغات.

1. يبلّغ المراجع، ثم يقبل المشرف أو يرفض.
2. يصدّر المشرف المقبول من «المراجعات ← تصدير المقبولة (JSON)».
3. يحوّل الملف المصدَّر إلى قائمة عمل مرتبة حسب الملف والمسألة:
   ```
   python scripts/reviews.py reviews-accepted-YYYYMMDD.json
   ```
4. تُعدَّل ملفات YAML، ثم يُعاد البناء بـ `python scripts/build_masail.py`، ثم يُرفع `qiraat.db` الجديد.
5. تُعلَّم البلاغات «طُبِّقت في المصدر».

مفاتيح الأهداف ثابتة عبر إعادة البناء:
- المسألة: `2-021`
- القراءة: `2-021#1`
- الموضع: `2-021@2:61:5`

لذلك تبقى البلاغات مرتبطة بأهدافها. وإن تغيّرت القيمة بعد البلاغ، تُظهر صفحته «القيمة الآن» بجوار «القيمة وقت البلاغ».

## البنية
```
app/
  public/        جذر الموقع: index.php (موجّه) و assets/
  src/           bootstrap.php (الاتصال والمساعدات والصلاحيات)، filters.php، layout.php، pages/*.php
  sql/reviews.sql  مخطط قاعدة المراجعات
  bin/create_user.php
  data/          reviews.db (لا يُرفع إلى git)
scripts/schema.sql  مخطط قاعدة المحتوى
```

## الأمان
- الاستعلامات كلها مُهيّأة (prepared).
- المخرجات كلها مُهرَّبة.
- النماذج كلها تحمل رمز CSRF.
- كلمات المرور مخزنة بـ `password_hash`.
- قاعدة المحتوى تُفتح للقراءة فقط.
