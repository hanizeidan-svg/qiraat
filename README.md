# قراءات — مسائل الشاطبية

**الهدف:** استخراج كل المسائل المعمول بها التي ذكرها الإمام الشاطبي في «حرز الأماني ووجه التهاني»، في جدول:
رقم الآية · نص الآية · الكلمة/الموضع · قول الشاطبي (رقم البيت ونصه) · النتيجة المعمول بها.

## البيانات الحالية
- `data/shatibiyya.json` / `data/shatibiyya.csv`: متن الشاطبية كاملًا مشكولًا (1173 بيتًا) بحقول: `n` رقم البيت، `bab` الباب، `sadr` الصدر، `ajz` العجز.

- `data/text_corrections.json`: تصحيحات موثقة لنص المتن (حاليًا: عجز البيت 466).
- `data/masail/*.yaml`: المسائل مستخرجة يدويًا من النظم. لكل قراءة: أصحابها، ولفظها (مكتوبًا أو مولَّدًا بتحويل كلمة حفص في كل موضع)، والأداء، والحال (وصلًا/وقفًا)، والدليل من النظم، والرمز.
- `data/out/` (نواتج البناء):
  - `qiraat_masail.xlsx`، وفيه ثلاث أوراق:
    - «القراءات»: صف لكل موضع × راوٍ × وجه. هذا هو الجدول الأساسي لاستخراج رواية كل راوٍ.
    - «الجدول»: صف لكل موضع مع عمود لكل راوٍ.
    - «المسائل».
  - `qiraat.db` (SQLite): المخطط في `scripts/schema.sql`. فيه جداول `masail` و`readings` و`reading_rawis` و`mawadi` و`qiraat` (موضع × راوٍ × وجه) و`matn`، والعرض المسطح `qiraat_v`.
  - `riwayat/`: رواية قارئ أو راوٍ مع أدلتها، مثلًا «ابن كثير».

### ما أُنجز
- **الفرش كاملًا** (الأبيات 445–1120): 1100 مسألة في 2340 موضعًا من 103 سور، بقراءة كل راوٍ من الأربعة عشر ولفظه ودليله.
  - ما حكمه عام نُصّ عليه في الفرش (حيث وقع) أُدرجت مواضعه كلها.
  - تُركت لمرحلة الأصول أبيات ياءات الإضافة والزوائد في أواخر السور.
- **أصول البقرة (نموذج):** هاء الكناية، والإمالة، والإدغام الكبير (1–20)، والإدغام الصغير، والياءات (السورة كاملة).
- **نقاط المراجعة المفتوحة:** [docs/REVIEW.md](docs/REVIEW.md)، تُولَّد بـ `python scripts/review_list.py`.
- **منهج الاستخراج:** [docs/METHOD.md](docs/METHOD.md).

### تطبيق الويب (PHP)
في `app/`: تصفح بالتصفية حسب القارئ أو الراوي، ومراجعة وتصحيح بحسابات للمراجعين. انظر [app/README.md](app/README.md).

### الاستعمال
```
python scripts/build_matn.py
python scripts/build_masail.py
python scripts/riwaya.py "ابن كثير"          # أو اسم راوٍ: "قنبل"
python scripts/riwaya.py "أبو عمرو" --khilaf  # ما خالف فيه حفصًا فقط
python scripts/reviews.py reviews-accepted.json  # قائمة عمل من مراجعات التطبيق المقبولة
```

### منهج التحقق
- يتحقق البناء من أن كل مسألة تغطي الرواة الأربعة عشر في حالَي الوصل والوقف، ومن أن كل تحويل للفظ قد طُبِّق فعلًا.
- تُستخرج المواضع آليًا من نص مصحف حفص.
- الحقل `review` يعلّم ما يحتاج تحريرًا.
